# SBOM fixtures

| File                                                           | Origin                                                                                                                                                                |
|----------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `bom-1.4.json`, `bom-1.5.json`, `bom-1.6.json`, `bom-1.7.json` | Generated by `composer generate-sboms` from this package's own dependencies. Do not edit by hand; changes are overwritten on the next run.                            |
| `bom-1.6-custom.json`                                          | Manually created fields the generator never emits, so parser tests can assert on schema-valid input. |

Every fixture must be registered in
`tests/Integration/SchemaComplianceTest::schemaFixtureProvider()`, so it is
validated against the official schema of its spec version.
